# v0.1.0

## What's included

- Core normalization engine (`normalizeToolOutput`) for `json`, `web`, `ocr`, `table`, and `text` fallback.
- Unified output schema with summary, key points, important fields, raw excerpt, warnings, and token metadata.
- OpenClaw plugin scaffold package with `openclaw.plugin.json` and `openclaw.extensions` entry.
- Basic test coverage and CI/publish workflows for open-source and npm delivery.

## Highlights

- Deterministic local normalization (no external model dependency).
- Configurable pruning, extraction, and warning behavior.
- Publish-ready package layout (`dist` outputs + manifest included in npm files).

## Non-goals

- No router/cache/budget orchestration.
- No external LLM API integration.
- No claimed deep runtime interception of all OpenClaw tool outputs.

## Installation

```bash
npm install openclaw-tool-output-normalizer
openclaw plugins install openclaw-tool-output-normalizer
```

## Notes / limitations

- This release focuses on normalization engine + plugin package scaffold.
- Deeper OpenClaw runtime hook integration should be added in future versions when stable hook APIs are documented.
